# LATENT - Multi-Phase Web & Network Pentest Tool

LATENT, web ve ağ hedefleri üzerinde çok aşamalı bilgi toplama ve zafiyet keşfi yapan bir penetration testing aracıdır.  
Kali Linux ortamı için tasarlanmıştır.

> ⚠️ Bu araç yalnızca yetkili sistemlerde ve eğitim amaçlı kullanılmalıdır. İzinsiz kullanım yasal değildir. Ve sorumluluk kabul etmeyiz.

---

## 🚀 Özellikler

- HTML içerik çekme (HTTP/HTTPS)
- Port tarama (TCP connect scan)
- SMB servis kontrolü
- Subdomain keşfi (wordlist tabanlı)
- XSS test denemeleri (basic payload checks)
- SQLMap otomatik tarama entegrasyonu
- Basit brute-force login denemeleri
- Detaylı rapor oluşturma (txt log)

---

- Python 3.x
- Kali Linux (önerilir)
